# Workbench screenshots

`world-editor.png`, `world-plots.png` and `world-export.png` are Chromium captures
of the locally served GNU Radio World editor with the RF extension. They show
synthetic radar protocol fixtures and a generated TX tone, not validated scene
propagation. Qualification edits the Python gain to 2, processes I/Q in actual
WebAssembly, inspects plot samples and exports a native TX/RX source package.
Example calibration/power are interface-fixture settings. Screenshots are not
mockups or desktop streams. See `scripts/qualify_world.py`.

The older Companion and Jupyter images document those separate historical
interfaces and are not screenshots of GNU Radio World.
